# Meal Tracker

## Descrição do Problema

Muitas pessoas não conseguem manter um controle consistente da alimentação diária. Isso dificulta a compreensão do consumo calórico e prejudica objetivos como emagrecimento, ganho de massa ou simplesmente hábitos mais saudáveis.

## Proposta da Solução

Esta aplicação permite registrar refeições com base em alimentos previamente cadastrados, calcular automaticamente as calorias consumidas e consultar o total por data.

## Público-alvo

- Pessoas iniciando controle alimentar
- Usuários que desejam simplicidade no registro de refeições

## Funcionalidades

- Cadastro de alimentos
- Registro de refeições com múltiplos alimentos
- Listagem de refeições
- Listagem de alimentos
- Remoção de refeições
- Remoção de alimentos
- Cálculo total de calorias por data

## Instalação

1. Clone o repositório:
   ```git clone <LINK>```

2. Acesse a pasta do projeto:
   ```cd meal-tracker```

3. Acesse a pasta do backend:
   ```cd backend```
   
4. Instale as dependências:
   ```yarn install```

5. Acesse a pasta do frontend:
   ```cd ..```
   ```cd frontend```

6. Instale as dependências:
   ```yarn install```
